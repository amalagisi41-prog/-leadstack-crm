# AgentStack Production Icon Pack

All exports are derived from the approved masters in `public/brand`. They preserve the approved artwork and are organized by placement.

## GoHighLevel Marketplace

Upload `marketplace/agentstack-marketplace-800.png`.

- 800 × 800 PNG
- 1:1 aspect ratio
- Approximately 323 KB, below the 500 KB marketplace limit
- The cream chevrons remain contained inside the blue tile

The 400 × 400 version is included as a fallback.

## App

`app/` contains square tile exports from 48 through 1024 pixels for app stores, mobile home screens, desktop launchers, and future native applications.

## Social

`social/` contains 400, 512, 800, and 1080 pixel profile images. These use the self-contained blue tile for reliable contrast across platforms.

## Web

`web/` contains browser, favicon, structured-data, PWA, and touch-icon sizes from 16 through 512 pixels.

## UI and media layouts

- `agentstack-mark-on-light-*`: use on white, cream, pale gray, or other light backgrounds.
- `agentstack-tile-transparent-edge-*`: use on dark, colored, photographic, or transparent layouts.

## Required contrast rule

Cream chevrons must never be placed directly on a light or white background. They may appear only as part of the approved blue tile artwork. Use the navy/coral `mark-on-light` files on light surfaces.

Do not recolor, stretch, rotate, crop through, or rearrange any export.
